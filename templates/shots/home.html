Version Notes v11

What Caddie Baddie does

  • Upload swing videos and extract GPS metadata to track shots.
  • Analyze videos on the server to compute shot distances and overlays.
  • Visualize shots on a Mapbox-powered hole map with draggable pin support.
  • Persist hole pins per-user and recompute distances server-side using haversine math.
  • Share and favorite shots, and group shots into rounds and courses.

Changes since last saved version

  • Added a server-side "Save Pin" flow that persists a per-user hole pin and recomputes all shot distances for the hole.
  • Shot distance recomputation now orders shots chronologically (oldest → newest) using stroke numbers, probe timestamps, or client timestamps.
  • Implemented a light in-memory smoothing pass to mitigate GPS outliers so putts and short shots calculate sensibly.
  • Expose per-shot diagnostics in the Save Pin API response to help debug origin/landing pairings and computed yardages.
  • Updated the hole map UI to include an "Unlock Pin" action that makes the pin draggable and a Save button that posts the selected pin to the server.
  • Fixed ordering and persistence issues and added migration for the HolePin model.
